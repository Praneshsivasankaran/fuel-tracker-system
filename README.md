# Fuel Tracking & Driving Behavior Analysis System

A full-stack system that tracks vehicle trips and analyzes driving behavior to estimate fuel efficiency.

## Tech Stack
- FastAPI
- PostgreSQL
- SQLAlchemy
- JWT Authentication
- HTML / CSS / JavaScript

## Features
- User authentication
- Vehicle management
- Trip tracking
- Driving efficiency scoring
- Dashboard visualization

## Project Workflow
1. User logs in
2. Registers vehicle
3. Records trip data
4. System analyzes driving behavior
5. Efficiency score is generated

## Future Implementation
- Mobile app (Android / iOS)
- GPS-based automatic trip tracking
- Google Maps route visualization
- Machine learning fuel prediction
